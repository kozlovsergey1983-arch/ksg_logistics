# Лендинг КСГ и вход в CRM

`index.html` — исходный сайт компании из предоставленного HTML-файла. В шапке
(включая мобильную версию) и подвале добавлены ссылки «Вход в CRM» на
https://kozlovsergey1983-arch-ksg-logistics-5ab5.twc1.net/ .
Ссылка открывает действующую CRM в новой вкладке. Авторизация выполняется в CRM.

## Публикация в Timeweb App Platform

1. Объедините этот PR с веткой `main`.
2. Создайте **отдельное приложение** из этого же GitHub-репозитория.
3. Ветка: `main`. Директория проекта / контекст сборки: `landing`.
   Dockerfile находится в этой директории. Порт приложения: `8080`.
4. После успешного деплоя проверьте временный адрес нового приложения.
5. Подключите к новому приложению домен `ksg-logistics.ru` и, при необходимости,
   `www.ksg-logistics.ru`. Используйте DNS-записи, показанные Timeweb для этого
   приложения; значения нельзя брать от другого приложения.
6. Проверьте HTTPS и переход «Вход в CRM» с компьютера и телефона.

Существующее приложение CRM продолжает работать по своему адресу `twc1.net`.
Его рабочую директорию, переменные окружения и подключение к PostgreSQL менять
не требуется. Данные CRM и учётные записи остаются в существующей базе.

Можно также разместить `index.html` на обычном статическом хостинге; все стили
и скрипты страницы встроены в HTML, внешних ассетов для отображения не требуется.

## Ограничения исходной страницы

Форма «Получить расчёт» в исходном HTML только показывает уведомление и не
отправляет заявку. Интеграция публичной формы с CRM в это изменение не входит.
Ссылки на политику конфиденциальности, оферту и FAQ также пока являются заглушками.
